# Code de conduite

ComfyForge souhaite offrir un espace accueillant, respectueux et constructif
à toutes les personnes qui utilisent le projet ou y contribuent.

## Comportements attendus

- Communiquer avec respect et bienveillance.
- Accueillir les retours techniques argumentés.
- Se concentrer sur les faits, le code et l’intérêt du projet.
- Respecter la vie privée et les droits d’auteur.
- Utiliser des exemples et des captures adaptés à un espace public.

## Comportements inacceptables

- Harcèlement, insultes, intimidation ou discrimination.
- Publication d’informations privées ou de secrets sans autorisation.
- Contenu sexuel explicite ou déplacé dans les espaces communautaires.
- Spam, promotion abusive ou perturbation volontaire des échanges.

Les mainteneurs peuvent modifier ou supprimer tout contenu contraire à ces
règles et limiter l’accès d’une personne qui les enfreint. Un incident sensible
peut être signalé de manière privée via l’onglet **Security** du dépôt.
